OpenrowDB **0.2.0** is the **maturity release** — months of UX backlog work in one drop: settings, power-user polish, global search, bulk data ops, typed inline editing, and index/FK management in the structure editor.

### Added

**Settings & onboarding**
- **Preferences (⌘,)** — default table page size, editor font size, history display limit, confirm-before-replace on history load
- **Onboarding sample connections** — try Local Postgres / Local MySQL with a pre-filled connection sheet
- **Connection form validation** — per-field errors on Save / Test Connection
- **Connection URL import** — paste `postgres://` / `mysql://` URLs into the connection sheet

**Query workspace**
- **Global search (⌘K)** — find connections, tables, open tabs, and query history from one palette
- **Query tab auto-title** — `SELECT * FROM users` suggests tab name `users`
- **History pin** — pin frequent queries; pinned entries sort to the top
- **History search** — filter the history inspector by SQL text
- **Edit menu** — Undo, Redo, and Find wired to the SQL editor
- **Help links** — GitHub repo and Report Issue from the Help menu

**Table viewer**
- **Multi-select rows** — ⌘-click / shift-range; bulk delete and copy as TSV
- **Paste rows (⇧⌘V)** — bulk insert from clipboard TSV/CSV with preview sheet
- **Column width persistence** — resized grid columns restore per table tab
- **Typed inline editors** — boolean picker, date/datetime pickers, JSON textarea by SQL type
- **Filter operators** — Contains, Equals, Not equals, `>`, `<`, Starts with, Ends with
- **Workspace breadcrumbs** — `db › schema › table` subtitle in the connection header

**Sidebar & connections**
- **Driver badge icons** — Postgres / MySQL visual cue on connection rows
- **Expandable schema folders** — collapse/expand schema groups (auto-expand while filtering)
- **Duplicate connection** — copy a saved connection in one click
- **Sidebar filter** — includes connection names, not just tables/columns

**Structure & DDL**
- **DDL preview** — see SQL before committing structure changes
- **Index editor** — list, create, and drop secondary indexes
- **Foreign key editor** — list, add, and drop outgoing foreign keys
- **Rename table sheet** — modern sheet replaces alert-based rename

**Tabs & workspace**
- **Tab drag-reorder** — persisted to `workspace.json`
- **Close Others / Close All** — tab strip context menu
- **Persist tab rename** — custom query tab titles survive restart

### Changed

- **DesignSystem** — shared `PlaceholderView`, `GlassIconButton`, `GlassMenuRow`, `DesignTokens`
- **Transfer menu** — glass popover consistent with Run / More menus
- **Shortcuts help (⌘/)** — documents new shortcuts including ⌘K, ⇧⌘V, multi-select

### Fixed

- **Export error feedback** — failed CSV/JSON export surfaces an alert instead of failing silently
- **DDL error messages** — sidebar and table mutations show specific failure text
- **Query results sort headers** — disabled for ad-hoc results (no misleading no-op sort)
