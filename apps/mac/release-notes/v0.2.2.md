OpenrowDB **0.2.2** adds multi-window workflows and restores sortable query results.

### Added

- **Multi-window** — **⌘⇧N** opens another main window (independent sidebar selection, shared connections and tabs). Right-click a connection → **Open in New Window** for a dedicated workspace window focused on one database.
- **Query result column sort** — click column headers to sort ad-hoc `SELECT` results and EXPLAIN output client-side (numeric-aware, NULLs last).

### Install

```bash
OPENROWDB_VERSION=0.2.2 curl -fsSL https://openrowdb.ryanprayoga.dev/install.sh | bash
```

Or download `OpenrowDB-0.2.2.dmg` from [GitHub Releases](https://github.com/ryan-prayoga/openrowdb/releases/tag/v0.2.2).
